Student Assignment Tracker

Project Overview

The Student Assignment Tracker is a command-line Python program designed to help students record and manage their homework and exam results in one place.

The program allows users to add assignments, view all recorded assignments, filter assignments by subject and calculate an overall grade summary.

Features

* Add homework assignments
* Add exam results
* View all assignments
* Filter assignments by subject
* Calculate overall percentage
* Display a letter grade
* Validate user input
* Handle invalid menu choices
* Uses Python classes and inheritance
* Runs directly in the terminal

How to Run

1. Clone the repository from GitHub.
2. Open the project folder in VS Code or a terminal.
3. Make sure Python 3 is installed.
4. Run the program using:

```bash
python main.py
```

Menu Structure

1. Add Homework
2. Add Exam
3. List Assignments
4. Filter by Subject
5. Grade Summary
6. Exit
