Short Reflection

Working on the Student Grade/Assignment Tracker helped me understand Python better because I had to apply different concepts together in one project. As a beginner, I did not remember every Python concept immediately, so while writing the code, I often had to go back to my class notes to remind myself how certain things worked. This helped me understand the concepts better instead of just trying to memorize them. I learned how to use functions, loops, conditionals, lists, classes, inheritance, and input validation. I also learned how Git and GitHub can be used to save my progress through different commits.

One of the biggest challenges I faced was remembering how to structure the code correctly. I sometimes had to go through my notes to understand how to create classes, use `super()`, pass parameters to functions, and work with loops. I also faced challenges when testing the program because small mistakes, such as incorrect indentation or a wrong variable name, could cause errors. Input validation was another challenge because I had to make sure the program could handle incorrect information without crashing. Although it took me time to understand these parts, checking my notes, testing the code, and fixing errors helped me learn.

If I had more time, I would improve the project by adding more features and making it more user-friendly. I would like to save assignments permanently in a file so that the information is not lost when the program closes. I would also add options to edit and delete assignments, sort them by date or score, and provide more detailed statistics for different subjects.

Overall, this project taught me that as a beginner, it is normal not to remember everything immediately. I learned that going back to my notes, experimenting with the code, and learning from errors are important parts of becoming a better programmer. This project has given me more confidence in Python and a better understanding of how different programming concepts work together.
